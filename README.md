# Mern Auth

![mern auth](https://github.com/user-attachments/assets/854ae312-b229-4006-ba02-2c87d49fe9ab)

The website demonstrates various user authentication techniques in a MERN web application.

## Features
- **User Authentication** – User can register and log in securely.
- **Update User** - Allows updating user name and email.

## Installation

1. Clone the repository:
    ```sh
    git clone https://github.com/midhunk0/mern-auth.git
    ```
2. Navigate to the project directory:
    ```sh
    cd mern-auth
    ```
3. Install client dependencies:
    ```sh
    cd client
    npm install
    ```
4. Install server dependencies:
    ```sh
    cd ../server
    npm install
    ```

## Usage

1. Start the backend server:
    ```sh
    cd server
    npm start
    ```
2. Start the frontend development server:
    ```sh
    cd ../client
    npm start
    ```
3. Open your browser and navigate to `http://localhost:3000`.

## Dependencies

- **MongoDB**
- **Express**
- **React**
- **Node.js**
